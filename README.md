# Spleisesparkel (arkivert)

Dette repoet er arkivert. `sparkel-aap` og `sparkel-dagpenger` ligger nå i
[navikt/helse-sparkelapper](https://github.com/navikt/helse-sparkelapper), sammen med de andre
sparkel-appene, og deployes derfra.
